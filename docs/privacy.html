Política de Privacidade

Última atualização: 23 de agosto de 2026

1. Sobre o aplicativo

O STL Auto Reply é uma ferramenta interna usada pela Imagine3D para monitorar comentários em publicações próprias do Instagram e enviar uma resposta privada automática quando uma pessoa comenta uma palavra-chave configurada, como "STL".

2. Dados processados

Para executar a automação, o aplicativo pode processar o nome de usuário público do Instagram, ID do comentário, texto do comentário, ID da publicação, data aproximada do evento, status de envio da resposta privada e informações técnicas de entrega.

3. Como usamos os dados

Usamos esses dados apenas para identificar comentários que acionam a automação, enviar a mensagem privada solicitada, evitar respostas duplicadas e diagnosticar falhas técnicas do serviço.

4. Compartilhamento

Não vendemos dados pessoais. Não compartilhamos dados com terceiros para publicidade. As mensagens e eventos são processados por serviços da Meta/Instagram e pela infraestrutura técnica usada para hospedar o aplicativo.

5. Retenção

Mantemos registros técnicos pelo tempo necessário para operar a automação, evitar envios duplicados e resolver problemas. Dados podem ser removidos mediante solicitação conforme as instruções de exclusão de dados.

6. Segurança

O acesso ao aplicativo e aos tokens de API é restrito. Segredos, tokens e chaves não devem ser publicados e são armazenados em ambiente controlado.

7. Direitos e exclusão de dados

Você pode solicitar a exclusão de dados relacionados à sua interação com o aplicativo. Consulte a página de Exclusão de Dados.

8. Contato

Para dúvidas sobre privacidade ou exclusão de dados, entre em contato pelo email cadastrado como contato do aplicativo no painel da Meta.
